# RealEstate10K loader

This package contains the video and camera-pose loader used by the released
LIVE RealEstate10K experiment. Actual videos belong under the configurable
`data/` root, not inside this source package.

The loader was adapted from Boyuan Chen's
[research template](https://github.com/buoyancy99/research-template); its MIT
license is retained in `licenses/research-template-MIT.txt`.
